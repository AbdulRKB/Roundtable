A Zoom-style classroom where every student is an AI agent. Share your slides, start talking, and watch the class react.

- **Live reactions:** emoji show how each student feels as you teach
- **They see your screen:** agents follow your slides and presentations
- **Shy students:** introverted agents type in the chat instead of speaking up
- **Real voices:** students ask questions out loud, powered by ElevenLabs

## Quickstart

```bash
npm install
cp .env.example .env   # add your API keys
```

```bash
npm run server   # terminal 1
npm run dev      # terminal 2
```

Open `http://localhost:3000` in browser → start a class → allow the mic → teach.
